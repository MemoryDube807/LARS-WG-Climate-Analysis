# Multi-GCM Ensemble Downscaling & Climatological Analysis

## Overview
This project automates the processing, ensemble averaging, and visualization of climate projection data generated by the LARS-WG stochastic weather generator. It applies dynamic anomaly calculations across custom Southern Hemisphere hydrological seasons (NDJ, FMA, MJJ, ASO) to assess localized climate vulnerability.

## Tech Stack
* **Language:** R
* **Libraries:** `tidyverse` (dplyr, tidyr, purrr), `ggplot2`, `plotly`, `pacman`

## Key Features
* **Automated Metadata Parsing:** Uses regex to extract General Circulation Model (GCM), Shared Socioeconomic Pathway (SSP), and time-period attributes directly from raw `.st` filenames.
* **Hydrological Alignment:** Reclassifies standard calendar months into agriculturally relevant quarters.
* **Dual-Palette Visualization:** Separates thermal and precipitation regimes into distinct color ramps (graduated blues for rainfall, sequential warm tones for heat) to reduce cognitive load.
